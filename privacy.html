YODIO Uploader — Privacy Policy

Last updated: 2026-11-24

YODIO Uploader is a private tool used only by the operator of the YODIO YouTube channel (@yodiomusic) to upload and schedule videos on that channel.

Data accessed

  • The tool requests YouTube API access (youtube.upload, youtube.force-ssl) only for the operator's own channel.
  • It uploads videos, sets titles, descriptions, captions, thumbnails and publish schedules, and reads basic statistics of the channel's own videos.

Data storage and sharing

  • The OAuth token is stored only on the operator's own computer.
  • No data is collected from other users, sold, or shared with third parties.
  • The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

YODIO Uploader는 YODIO 유튜브 채널(@yodiomusic) 운영자 본인만 사용하는 도구로, 해당 채널에 영상을 업로드하고 공개 예약을 설정하는 용도로만 사용됩니다.

  • YouTube API 권한(업로드, 자막 관리)은 운영자 본인 채널에만 사용합니다.
  • 인증 토큰은 운영자 본인의 컴퓨터에만 저장됩니다.
  • 다른 사용자의 정보를 수집하지 않으며, 제3자에게 판매하거나 공유하지 않습니다.
  • 권한은 Google 계정 권한 페이지에서 언제든지 해제할 수 있습니다.
